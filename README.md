### **Learn CUDA**

A collection of CUDA learning exercises and implementations, covering fundamental GPU programming concepts through progressively more involved examples.

**Contents**

- Vector addition — CPU vs. GPU implementation
- Matrix multiplication — CPU and CUDA implementations
- Julia set generation — CPU and CUDA implementations
- CUDA development environment and setup notes

**Purpose**

This repository serves as a personal reference for learning and revisiting CUDA programming, with implementations written from the fundamentals up.

More examples and experiments will be added as needed.
